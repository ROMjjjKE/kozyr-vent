# ИП Козырь И. В. — вентиляция

Приточные и вытяжные системы для цехов, складов и офисов в Минске. Изготовление воздуховодов и
монтаж одной бригадой. Телефон +375 29 128-24-17.

**Живой сайт:** https://romjjjke.github.io/kozyr-vent/

## Что внутри

- Герой: индекс пяти систем (приток, вытяжка, баланс, отсосы, воздуховоды) и телефон.
- Пин-сцена «этапы»: горизонтальная лента из пяти карточек (замер → смета → изготовление →
  монтаж → пуск), едет вбок по скроллу, снизу рельс 01–05 с подсветкой активного этапа.
- Склад: шесть категорий оборудования и честная оговорка, почему перечень не публикуется прайсом.
- Полоса объекта: одна фотография цеха с технической подписью.
- Смета: пять факторов цены вместо выдуманного прайса.
- FAQ на `<details>`, форма заявки в WhatsApp, блок заявки на светлой панели для контраста.

## Стек

React + Vite + TypeScript, GSAP + ScrollTrigger (лениво, только для горизонтальной сцены), Lenis.
Шрифты самохостингом: Wix Madefor Display 700/800 + Commissioner 400/600, 92 KB на 8 файлов,
метрические фолбэки (`size-adjust` 105,1% и 103,7%). Фото 194 KB (1400 px) + 47 KB (640 px).

## Ограничения

Прайса нет: цен и сроков на сайте не выдумано, есть только состав сметы и правило «цифры до работ».
Перечень склада не публикуется по позициям: наличие меняется, в тексте это сказано прямо.
Фотография одна и взята из объявления заказчика: водяной знак площадки обрезан, снимок сильно
апскейлен до 1400 px, о чём честно сказано в подписи «объект с действующим производством».
